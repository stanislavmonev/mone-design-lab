# MONE Design Lab

Experimental Next.js design laboratory for premium, accessible, responsive websites.

## Start

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Design guidance

Read `AGENTS.md` and `skills/modern-frontend/SKILL.md` before editing UI. These are project-local instructions, not globally installed ChatGPT skills.

External UI/UX Pro Max is **not installed**. Its source must be reviewed and version-pinned before importing.
